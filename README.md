# ProAuto - Website Bengkel Mobil

Website untuk bengkel mobil yang menonjolkan servis rapi, cepat, dan transparan.

## Fitur
- Daftar layanan servis
- Alasan memilih bengkel
- Galeri pengerjaan
- Testimoni
- Alur booking servis

## Teknologi
HTML, CSS, dan JavaScript (tanpa framework).

## Cara menjalankan
Clone repo ini lalu buka `index.html` di browser.
